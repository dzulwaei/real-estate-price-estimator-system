# Requirements

## Functional requirements 
1. [FR1] The system shall allow users to input property attributes, including location, square footage, number of bedroom/bathrooms and property age.
2. [FR2] The system shall calculate and display an estimated property market value vased on the submitted property attributes. 
3. [FR3] The system shall display a list of comparable recently sold properties based on proximity and feature similarity. 
4. [FR4] The system shall allow users to generate and download a comprehensive PDF valuation report for any estimated property. 
5. [FR5] The system shall periodically update its dataset with recent market transaction records to maintan accurate predictive models.

## Non-functional requirements 
1. [NFR1] The system shall calculate and display price estimates within 2 seconds after the user submits the property details.
2. [NFR2] The system shall maintain a web platform availability uptime of 99.9%.
3. [NFR3] The system shall achieve an estimation accuracy with Mean Absolute Percentage Error (MAPE) of under 10% on test datasets.
